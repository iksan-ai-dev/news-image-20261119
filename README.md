front page with the Shenzhen trilateral summit as its lead, four cross-region
stories beside it, and a briefs ticker.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to the output directory. `gen.py` is the program that
drew the image (PIL, deterministic — same bytes on every run).
